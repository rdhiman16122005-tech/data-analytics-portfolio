# Business Requirements & Process Improvement (Excel, Draw.io, Jira, Word)

Scenario-based business analysis project: a retail company has a slow order-processing system.

## Deliverables
| File | Contents |
|---|---|
| `01_BRD.md` | Business Requirements Document: problem, objectives, scope, stakeholders, requirements, KPIs, risks |
| `02_process_flows.md` | AS-IS and TO-BE process flows (Mermaid diagrams - GitHub renders these), bottleneck analysis |
| `03_user_stories.md` | User stories with acceptance criteria, prioritised (MoSCoW) |
| `04_recommendations_report.md` | Recommendations, expected benefits and an implementation roadmap |

## Tools
Excel (requirements traceability / KPI tracking), Draw.io (export the diagrams as PNG/PDF into `/diagrams`),
Jira (create the epics and stories in a project and add screenshots to `/images`), Word (formal BRD version).

> This is a **scenario-based** project: the company, data and figures are fictional. Where a number
> is needed, it is marked as an *assumption* - replace them with your own reasoning.
